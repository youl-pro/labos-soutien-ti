# Labos de soutien informatique

Laboratoires pratiques réalisés pour me préparer à un poste de technicien en soutien informatique (niveau 1). Chaque labo suit la même démarche : identifier le problème, tester des théories, mesurer, vérifier et documenter.

## Laboratoires

| # | Labo | Compétences travaillées |
|---|---|---|
| 01 | [Diagnostic d'un ordinateur lent](01-diagnostic-memoire/) | Gestionnaire des tâches, analyse de la mémoire, programmes au démarrage |
| 02 | [Deux réseaux reliés par un routeur](02-routeur-passerelle/) | ipconfig, ping, tracert, passerelle par défaut, dépannage réseau |

## Méthode de dépannage

1. Identifier le problème
2. Établir une théorie
3. Tester la théorie
4. Appliquer le plan d'action
5. Vérifier le résultat
6. Documenter

## Outils utilisés

Windows 11, Gestionnaire des tâches, Cisco Packet Tracer
